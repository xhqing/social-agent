# 雪球运营参考

> 来源：雪球官方《社区规则》（xueqiu.com/about/faq/all，2026-11-16 逐条取证）+ 官方 FAQ + 公开报道。
> 时效提醒：平台规则变化频繁，引用条款前复查最新版本。
> 一句话定位：**雪球能做专业信誉和站内关系，做不了站外导流。** 本文件所有纪律都从这一条推出来。

## 一、平台定位与规模

| 项目 | 事实 |
|---|---|
| 定位（官方原文） | 「雪球社区定位为专业性的垂直类社区，聚焦以股票和基金为代表的『权益类资产』投资相关的内容和话题。」（第一章第 1 条） |
| 成立时间 | 2010 年 3 月，投资者垂直社交媒体 |
| 规模 | 官网口径「超过 7800 万投资者」；2026-04 证券服务类 App 活跃榜里雪球环比 +2.8%，位列第三 |
| 内容形态 | 讨论帖（短帖）、雪球专栏（长文）、雪球组合 / 实盘组合、直播、悬赏、打赏、私信 / 聊天、群组 |
| 群组 | 上限 100 人，群主可命名 / 邀请 / 踢人（官方指南，年代较早，现状需在 App 内确认） |
| 收录情况 | 页面被搜索引擎收录，是长尾来源的主要通道 |

**这张表决定了雪球在矩阵里的位置**：读者是投资者、题材是权益类资产，内容匹配度比小红书高一个量级；代价是平台对导流与荐股的管束也是所有阵地里最严的。

## 二、导流：所有出口都关着（核心纪律）

雪球禁导流的地方分四处，覆盖了几乎所有手法。

### 2.1 内容与账号信息（第八章第 1 条）

> （1）在昵称、简介、头像和发布的内容中，以文字、图片或视频等形式附加**站外联系方式**（如电话号码、二维码、**第三方平台链接**等），附加带有营销性质的站外链接（如电商平台链接、知识付费类课程等）；
> （6）诱导用户通过**回复关键词、关注并发私信**等方式获取资源的（如领取电子书、领取 PDF、领取音频、视频资源、领取其他资料或教程等）；
> （7）通过抽奖、红包、分享福利、分享资料等利益诱导方式，诱导用户添加联系方式或引导至站外……

### 2.2 账号信息（第十三章第 1 条）

> （9）账号信息不应包含任何形式的联系方式**其他诱导导流信息**（包括**变体或特殊字符**）。

### 2.3 私信（第十一章 + 第十四章）

> 第十一章 3（3）：使用私信功能：**不得通过私信发送广告**、骚扰其他用户或发送违法违规信息；
> 第十四章 2 适用范围（5）：**用户通过 IM 私信发送的所有信息内容**。

### 2.4 目的条款（第六章第 1 条）

> （4）诱导其他用户到**微信、QQ、微博、知识星球等站外平台**进行付费阅读，提供诊股、解股、解盘等服务，诱导用户购买或向用户提供各种形式的炒股类课程……

### 2.5 逐项对照表

| 做法 | 判定 | 依据 |
|---|---|---|
| 正文 / 简介放 GitHub、博客、公众号链接 | ❌ 违规——「第三方平台链接」就写在「站外联系方式」的举例里 | 8-1(1) |
| 简介写「公众号：某某」 | ❌ 违规 | 13-1(9) |
| 写「全网同名」「同名账号」 | ❌ 违规——属诱导导流信息，且形态接近暗语 | 13-1(9)、6-1(11) |
| 「回复关键词领资料 / 领代码」 | ❌ 违规，逐字命中 | 8-1(6) |
| 私信给微信号 / 邮箱 / 电话 | ❌ 违规——对方先开口也不豁免，条款没有「谁先问」这个前提 | 11-3(3)、14-2(5) |
| 拆写规避（`xxx at gmail dot com`、`vx`、`+V`） | ❌ 违规且性质更重——明确规避 | 13-1(9) |
| 头像图上印二维码 / 联系方式 | ❌ 违规——条款写明「以文字、图片或视频等形式」 | 8-1(1)、13 |
| 投稿 / 广告合作 | ✅ 官方路径：`ad@xueqiu.com` | 8-2 |

**唯一的合法站外出口**：第八章第 2 条——「如需进行广告合作，请联系雪球官方邮箱（ad@xueqiu.com）进行接洽」。个人账号拿不到。

### 2.6 处罚烈度

- 处理手段：删除内容、退回修改、**限时加私（限制展示）**、加标签、临时昵称 / 头像、删违规简介、**禁言、关闭账号**、限制提现、**禁止重新注册**、清理违规获得的粉丝（第十四章 1）
- 2026-01-20 雪球一日连发三批公告，**永久封禁 22 个大 V**（「杭州新城路」「轮回666」「福禄娃爷爷」等）
- 第六章第 2 条列明：**向证券监管机构或公安机关报告相关行为线索**——这是规则里唯一出现「公安」的地方

## 三、金融合规：比导流更重的一条

### 3.1 非法荐股条款（第六章第 1 条）

> （4）诱导其他用户到微信、QQ、微博、知识星球等站外平台进行付费阅读，提供诊股、解股、解盘等服务……
> （6）通过发布**炫耀展示所谓炒股技术方法、买卖交割单、账户收益、炒股牛人**等信息，诱导其他用户加群或去各类平台找 XXX 人学习炒股等；
> （11）其他具有「非法荐股」等非法证券投资咨询活动嫌疑的骚扰用户行为，包括发布或向其他用户发送**暗语类信息**……

### 3.2 「股神人设」单独列为不受欢迎内容（第三章第 2 条）

> 通过发布**账户盈亏截图、神预言**等，炫耀个人操作技巧、**打造股神人设**，诱导用户打赏或将用户引导至雪球社区外，意图开展「非法荐股」等非法证券投资咨询活动。

### 3.3 对内容的直接约束

| 内容类型 | 能不能发 | 说明 |
|---|---|---|
| 方法论、机制推导、回测方法、统计检验 | ✅ | 属「技术与知识」方向，雪球鼓励的专业内容 |
| 策略逻辑、参数选择、边界与失效条件 | ✅ | 这是雪球最欢迎的一类（第二章「有思考、有见解、有逻辑、言之有物」） |
| 账户盈亏截图、实盘收益曲线、交割单 | ❌ | 与「打造股神人设」直接撞车，专项整治的打击重点 |
| 具体标的推荐、买卖点、预测股价 | ❌ | 无投顾资质即涉非法经营罪，罚没金额可达千万级（金某案：罚没 8325 万元 + 3 年市场禁入） |
| 带单、跟单引导、代客理财 | ❌ | 第六章第 1 条（3）专项禁止 |
| 晒策略但引导「加群一起做」 | ❌ | 第六章第 1 条（6）的完整构成要件 |

**边界**：单纯分享方法论不违规；「展示 + 诱导」的组合才构成违规。雪球的任何地方都不做诱导动作。

## 四、AI 标注（明文要求）

> 第十二章第 4 条：为避免误导他人，用户发帖如涉及 AI 生成内容，应主动**勾选 / 添加 AI 生成内容标识**。

这条是全平台里写得最明确的之一。发布时勾选，与项目「AI 做辅助、人做核心」的纪律一致。

## 五、承接设计：站内四件套

雪球给不了站外出口，站内能给的其实不少——把这四样做扎实，读者不需要离开雪球也能持续跟着你。

| 工具 | 作用 | 注意 |
|---|---|---|
| **关注** | 最基本的关系，发帖进关注流 | 门槛最低，所有内容都该服务这一项 |
| **专栏** | 长文连载容器，可命名、可订阅 | 系列化运营的主阵地（`AGENTS.md` 已有「一篇双版」纪律，雪球放专业版） |
| **模拟组合 / 实盘组合** | 把方法论跑成一条可查的净值曲线 | 雪球独有、其它阵地没有的信任资产；**不能用来做跟单引导** |
| **群组** | 100 人上限的站内讨论组 | 官方指南年代较早，开通条件需在 App 内确认 |

**站外不导流，站内不设防**：读者在雪球继续互动、在专栏追更、在组合看净值——这些都是合规的，而且比一个微信好友的粘性高。

## 六、内容策略

### 6.1 定位：一篇双版里的「专业版」

`AGENTS.md` 的选题纪律第四条要求「一篇双版」——专业版不期待流量，作用是给科普版兜准确性。雪球是这个专业版最自然的两个落点之一（另一个是 GitHub）。

- 公式照写，推导不删；
- 回测细节、统计检验（t 检验、置信区间、多重比较）能写就写；
- 代码以文本或截图给出，不给可点击链接；
- 评论区的追问（样本期多长、幸存者偏差怎么处理、参数敏不敏感）是压力测试——讲不出边界的地方会当场暴露。

### 6.2 让标题成为搜索词

雪球页面被搜索引擎收录，内容的长尾靠搜索词支撑。**把系列名做成品牌词、全平台复用**，比任何导流话术都有效：

- 雪球读者看完一篇，站内搜系列名 → 找到同系列；
- 站外读者搜系列名 → 搜到全部阵地；
- 规则上一个字都不碰——系列名是内容标识，不是联系方式。

对比「全网同名」：那四个字是让读者去找人，属导流指令；系列名是让读者去找内容，平台不管。而人找内容的动机比找一个人强得多。

### 6.3 与其它阵地的分工

| 阵地 | 承担的职能 |
|---|---|
| 雪球 | 让人**认识你**（专业信誉、被搜到、被追问） |
| GitHub / 公众号 | 让人**找到你**（公开可搜的邮箱与全部入口） |
| 公众号菜单 | 把人**接住**（站内可用的承接功能） |

雪球这一格不放任何站外信息，整体上仍然可被联系到——因为正经想找你的人会从 GitHub 和公众号找到你。

## 七、变现

对无投顾资质的个人，雪球站内合法收益只有两项：

| 方式 | 说明 |
|---|---|
| **打赏** | 站内功能，需遵守《打赏功能使用规则》（第十一章第 2 条） |
| **悬赏** | 单日可接收悬赏及悬赏活动累计金额**上限 1000 元**，次日恢复（第十一章第 3 条） |
| 官方广告合作 | `ad@xueqiu.com`（第八章第 2 条） |

没有内容分成，也没有付费专栏通道。雪球的价值在影响力与信誉，不在直接收入。

## 八、遇事的处理顺序

1. **内容被限**（限时加私 / 不展示）：先看是否含联系方式、站外链接、暗语类表述——雪球的「限时加私」是限制展示，不是删除，改掉相关内容后通常可恢复；只改有问题的那一条，**不批量删文**。
2. **账号被禁言 / 功能受限**：查雪球安全中心公告，按官方申诉入口提交；不重复注册（规则明写「禁止重新注册」属处理手段）。
3. **收到合规提醒**：按 `AGENTS.md` 红线三的分级重新判定内容属于哪一档，必要时把标的与买卖点全部删掉，只留方法。

## 九、待确认项

- 群组功能的当前状态与开通条件（官方指南年代较早）；
- 专栏 / 讨论帖的字数上限与图片规格（发布前在编辑器内实测）；
- 认证账号在简介与内容上是否有不同的审核尺度（规则文本没有给任何账号类型开导流口子，不要据此规划）。
