交易之魂：量化复利

复利这件事很多人很可能根本没想透彻。大家都知道复利就像滚雪球，但是，这个雪球一定要滚十几年甚至几十年吗？

在交易领域虽说交易策略不必非得是量化策略，但是能量化的策略或者是量化程度较高的策略才有更透明且更科学的可解释性。复利由于其指数爆炸特性，在交易领域不是可选项而是必选项，因为交易本身是要冒风险的，策略潜力必须足够高才值得冒险，也就是你的策略收益率曲线要有指数爆炸的潜力才值得入场（应该没有潜力更高且合理的形态），因此为了拥有足够高的可解释性，量化复利是交易必须的核心手段。

复利的本质其实就是这一行公式（n 足够大时才成立）：

Wₙ / W₀ ≈ e^(n·g)，其中 g = E[ln(1 + fR)]

W₀ 是开始时的本金，Wₙ 是 n 笔交易之后的本金。这里的“≈”来自大数定律，笔数 n 要足够大才近似相等；笔数少时误差可能很大。

三个符号各是什么：

· g 是平均增长率（对数口径），通俗说管“保底不亏”
· f 是每次下注的资金比例，通俗说管“能做风控”
· n 是第 n 笔交易（n 够大），通俗说管“指数爆炸”

这行公式是怎么来的？为了让尽可能多的读者能够轻松理解，推导过程会尽可能详细。

第一步：一次冒险，就是给当前财富乘一个倍数。

假设手里有 1 万块（初始总资产 W₀），拿本金的固定比例 f 去冒险——比如 f = 10%，也就是 1000 块；这一次冒险的结果可能挣钱也可能亏钱，但是亏钱最多只亏得了 1000 块钱，不论结果是挣是亏，这 1000 块钱肯定会变成某个 1000 的倍数，假设这个倍数为 R，则一次冒险之后 1000 块变为 1000R，这个 R 叫做赔率，由于最多只亏得了 1000 块钱，所以 R ≥ -1。用公式表达这次冒险的盈亏就是 f·W₀·R，于是做完一次冒险总资产变为：

W₁ = W₀ + f·W₀·R = W₀(1 + fR)

把括号里的 1 + fR 记作 m：m 就是“这一次冒险让财富变成原来的 m 倍”的意思——赚 10% 是 m = 1.1，亏 5% 是 m = 0.95。

第二步：冒险 n 次，就是乘 n 次。

Wₙ = W₀ × m₁ × m₂ × … × mₙ

每一次都乘在上一次的结果上——这就是“复利”两个字的全部作用：这一次的本金是上一次的结果，所以赚到的钱自己也会生钱。

假设三次分别赚 10%、亏 10%、赚 20%，别误以为“净赚 20%”，实际是：

1.1 × 0.9 × 1.2 = 1.188

净赚 18.8%，比 20% 少了 1.2 个百分点。少掉的这点就是波动吃掉的——赚 10% 再亏 10%，回到 0.99，已经亏了 1%。

第三步：平均每一笔增加多少倍。

n 笔之后，总倍数是 ∏m(i)（i 从 1 到 n）。把总倍数开 n 次方得到平均每一笔增加的倍数：

Gₙ = (∏m(i))^(1/n)，i 从 1 到 n

它的意思是：如果每一笔都恰好变成 Gₙ 倍，做 n 次得到的总倍数，与实际一模一样。上面三次：G₃ = 1.188^(1/3) ≈ 1.0591，而 1.0591³ = 1.188，分毫不差。

第四步：n 足够大的时候，Gₙ 会稳定到哪个数？

小样本计算出的 Gₙ 不可靠，运气好的时候偏大，运气差的时候偏小。样本足够大的时候会稳定在什么数值范围？如果稳定在小于 1 的数值范围则亏钱是大概率事件，这不是我们想要看到的结果。

难点在于 Gₙ 是“乘积开方”，没有一个直接管乘积的极限定理；而我们最终要的不是某一批样本的 Gₙ，是它的长期期望。因此取对数把它的乘法形态变为加法形态：

ln Gₙ = (1/n)·ln(Wₙ/W₀) = (1/n)·Σln m(i)，i 从 1 到 n

乘积变成和，“每笔的几何平均”变成“每笔对数收益率的算术平均”，记作 gₙ，这样大数定律才能派上用场。所以取对数不是为了好算，是为了把乘积翻译成和，让这个量能求极限、求期望。

第五步：次数够多，这个平均数才会稳定到期望值。

这就是大数定律：样本越多，样本平均越接近期望。抛硬币一百次，正面比例贴近 50%；做了几百笔之后，gₙ 贴近

g = E[ln m]

单笔是随机的，但长期结果由这个期望决定，不由某一笔的好坏决定。

第六步：把平均值代回去，指数就出来了。

ln(Wₙ/W₀) ≈ n·g，于是 Wₙ/W₀ ≈ e^(n·g)

注意这个“≈”是从哪里来的：它们靠的正是第五步——只有 n 足够大，样本平均 gₙ 才贴近期望 g。写成极限更清楚：

(1/n)·ln(Wₙ/W₀) → g（n → ∞）

也就是说，“约等于”准确说是“对数尺度上的约等于”：n 越大，(1/n)·ln(Wₙ/W₀) 越贴近 g，e^(n·g) 给出的长期平均路径越准；但具体到某一段，实际值会围着它上下浮动，不会正好落在上面。

有了这个极限，最后一步只用了对数的反函数：ln x = y 等价于 x = e^y，就把和式还原成指数。把 m = 1 + fR 代回去，就是开头那行公式：

g = E[ln(1 + fR)]，Wₙ/W₀ ≈ e^(n·g)

为什么一定是指数，不是直线？

因为每一步都在前面的结果上乘一个（长期平均下来）固定的倍数。“固定倍数反复相乘”就是指数的定义——只要每笔按本金的比例赚，结果必然是指数；反过来，每笔赚固定金额（比如工资），连乘这一步就不存在，只能是直线。

g 和 n 的实际威力：g = 3% 时，做 50 次是 e^1.5 ≈ 4.48 倍；想让财富翻倍，需要 n ≈ ln2 / g = 0.693 / 0.03 ≈ 23 次。
